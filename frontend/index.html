How It Works

1

Address Geocoding

Type a place name and the backend resolves it to coordinates through OpenStreetMap Nominatim.

2

Shortest-Path Routing

Coordinates go to the OSRM engine, which returns the optimal route geometry and turn instructions.

3

Telemetry & Costing

Distance, mode-adjusted ETA and an estimated travel cost in ₹ are computed for Drive, Bike or Walk.

4

SQLite Persistence

Save destinations to navigator.db and reload them into the planner whenever you need.

Frequently Asked Questions

How is routing calculated?

The Flask backend calls the public OSRM routing engine, which finds the shortest path over OpenStreetMap road data and returns geometry plus step-by-step maneuvers.

How are addresses found?

Nominatim geocodes free-text queries into latitude and longitude. The backend returns the top five matches so you can pick the right one.

How does the Flask REST API fit in?

The browser only talks to Flask. Flask handles Nominatim, OSRM and SQLite, which avoids CORS problems and keeps third-party calls off the client.
